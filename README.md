# IEEE-BE-NodeJS-Beginner

This repository contains my solutions to the **Beginner-level Node.js tasks** from the [IEEE Backend Roadmap 2025](https://github.com/saifsweelam/IEEE-Backend-Roadmap-2025/tree/main/Node.js/beginners).

The tasks cover core Node.js concepts like working with built-in modules (`fs`, `path`, `http`, etc.), asynchronous JavaScript patterns, simple HTTP servers, and basic CLI utilities.
