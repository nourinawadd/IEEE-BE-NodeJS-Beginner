# Hangman CLI Game

This is a simple Hangman game built with JavaScript using object-oriented programming (OOP) principles. It runs entirely in the terminal using Node.js.

## Requirements

- Node.js installed on your system (v12 or later)

## How to Run

1. Download or clone the project files.

2. Open a terminal in the project directory.

3. Run the game with the following command:

```bash
node app
